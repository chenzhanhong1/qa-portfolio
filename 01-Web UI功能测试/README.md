# Web UI 功能测试（登录 + 弹窗）

## 项目是什么

对一个 Web 练习网站的**登录**和**弹窗**模块做功能测试：设计 16 条用例、逐条执行、截图留存、记录缺陷、输出测试总结。

## 目录

| 目录/文件 | 内容 |
|---|---|
| `01_测试用例/登录测试用例.xlsx` | 登录模块 7 条用例 |
| `01_测试用例/弹窗测试用例.xlsx` | 弹窗模块 9 条用例 |
| `02_测试截图/登录截图/` | 7 张登录执行截图 |
| `02_测试截图/弹窗截图/` | 9 张弹窗执行截图 |
| `03_缺陷管理/缺陷记录.xlsx` | 3 个缺陷记录（S3 / P1） |
| `04_测试总结/Web UI 功能测试实践总结.docx` | 测试总结 |
| `登录测试点.png`、`弹窗测试点.png` | 测试点梳理图 |

## 我做了什么

1. 分析登录、弹窗功能，梳理测试点；
2. 用**等价类、边界值、判定表、场景法**设计 16 条用例（登录 7、弹窗 9）；
3. 逐条执行，记录实际结果，截图留存；
4. 对不符合预期的 3 条记录缺陷：
   - 用户名为空时，提示“用户名或密码错误”，而不是“请输入用户名”；
   - 密码为空时，提示“用户名或密码错误”，而不是“请输入密码”；
   - 用户名和密码都为空时，没有分别提示必填项；
5. 输出测试总结。

## 结果

- 16 条用例：13 条通过，3 条失败；
- 3 个缺陷：S3 / P1，已记录复现步骤、预期/实际、截图。

## 面试怎么讲

> 我给一个 Web 练习网站的登录和弹窗模块设计了 16 条用例，用等价类、边界值、判定表、场景法梳理测试点；执行时发现空用户名、空密码、两者都空这三种情况，页面都提示“用户名或密码错误”，而不是分别提示“请输入用户名/密码”，我记录了 3 个缺陷，附了截图和复现步骤。
